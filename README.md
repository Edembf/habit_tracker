# habit_tracker
## What this is
A small Flutter habit-tracking app (mobile + web targets) that stores user profile info and habit lists locally using shared_preferences. It provides a login/register flow, a configurable list of habits with colored cards, and simple swipe-to-complete behavior.

### Stack
- Language(s): Dart (Flutter) — primary. Repository also contains platform folders (Android/iOS/web/desktop) generated by Flutter.
- Framework / runtime: Flutter (stable; see pubspec environment sdk ^3.11.1)
- Notable libraries:
  - shared_preferences — local key/value persistence for user data and habit maps
  - http — used to fetch the country list (restcountries API)
  - fluttertoast — small toast notifications
  - flutter_local_notifications — listed in dependencies (not currently used in code files inspected)

How it fits together:
- Entry point: lib/main.dart initializes a MaterialApp and opens LoginScreen.
- Authentication flow:
  - lib/login_screen.dart — authenticates with a hard-coded default account (testuser / password123) and writes profile fields into shared_preferences.
  - lib/register_screen.dart — collects name/username/age/country and selected habits, assigns random colors, and stores them in shared_preferences as JSON under selectedHabitsMap.
- Main app:
  - lib/habit_tracker_screen.dart — reads selectedHabitsMap and completedHabitsMap from shared_preferences, displays "To Do" and "Done" lists, and allows dismiss/swipe to move items between maps.
  - lib/add_habit_screen.dart — UI for creating a custom habit and choosing a color. Saves habit entries to selectedHabitsMap (color saved as hex from Color.value.toRadixString(16)).
- Useful code pieces:
  - lib/country_list.dart — fetches country names from restcountries.com.
  - Data keys in shared_preferences: 'name', 'username', 'age', 'country', 'selectedHabitsMap', 'completedHabitsMap'.

## How to run it
Shortest path from a fresh clone to running locally (Flutter required). Run from repo root:

```
# get dependencies
flutter pub get

# run on default connected device (or pass -d <device_id>)
flutter run

# run for web
flutter run -d chrome

# run tests (if added)
flutter test
```

Notes:
- The app stores data locally via shared_preferences; no backend required.
- The Register screen calls restcountries.com to populate the country dropdown — device/emulator must have network access for the list to populate.
- Default login credentials (for quick access): username = testuser, password = password123

# Habitt — Habit Tracker (Flutter)

A small, local-first habit tracker built with Flutter. It provides a simple register/login flow, lets users select or create habit cards with colors, and move habits between "To Do" and "Done" by swiping. Data is saved locally using shared preferences — no backend required.
